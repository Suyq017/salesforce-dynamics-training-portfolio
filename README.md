# Salesforce & Dynamics 365 Training Portfolio

This repository contains my hands-on exercises from a Salesforce and Microsoft
Dynamics 365 training program. The projects are organized by platform and
technology so that each exercise can be reviewed independently.

## Contents

### Salesforce

- Salesforce DX source: Apex classes, triggers, Visualforce pages, Aura
  components, Lightning Web Components, batch jobs, and test classes
- SOQL and Apex scripts under `SFDC/scripts`
- PDF rendering with Visualforce

### Microsoft Dynamics 365

- Batch processing exercises
- Dataverse plugins
- Web resources
- Power Apps Component Framework (PCF) controls

### .NET

- `SFDC .Net/StudentDataCreate`: a .NET exercise integrating student data

## Learning roadmap

1. Visualforce pages
2. Aura components
3. Lightning Web Components
4. Apex triggers
5. Apex batch processing
6. Apex test classes
7. .NET integration
8. PDF generation
9. Dynamics 365 environment and Power Platform development

## Repository hygiene

Generated dependencies, IDE state, build output, local logs, credentials,
certificates, and third-party sample repositories are intentionally excluded
from version control. Install the dependencies required by each project before
running it.

## Notes

These projects were created for learning and portfolio purposes. Salesforce
and Dynamics 365 solutions may require an appropriately configured developer
environment, organization, or Dataverse instance to run.
